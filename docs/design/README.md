# Creative studio visual studies

Open `hub.html` and `drawing.html` in a browser. Both adapt to desktop and phone widths. The examples are fictional fixtures and all controls are visual placeholders; these pages do not access accounts or send messages. The first implementation uses the same design tokens in `src/app/studio.css`.

Direction: warm ivory, charcoal, vermilion, clean interface type with expressive serif display accents. Review at 1440px and 390px, and check for overflow at 320px. Drawing studio implementation, drafts, and the later phases remain tracked in TASKS.md.

Verification: reviewed desktop and 390px layouts in Chrome; narrow 320px layouts had no horizontal overflow. These standalone studies use the system sans-serif fallback; the implemented app loads Geist.
